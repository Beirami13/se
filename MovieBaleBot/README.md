# CineLog Bot 🎬

یک بات ساده در پیام‌رسان «بله» برای ثبت فیلم‌ها و سریال‌های دیده‌شده و آنهایی که می‌خواهی ببینی؛ همراه با امتیاز و نقد شخصی. هر کاربر فقط داده‌های خودش را می‌بیند.

## امکانات

- افزودن فیلم یا سریال به‌صورت قدم‌به‌قدم (با دکمه، بدون حفظ کردن دستور)
- نمایش فهرست همه‌ی آثار، فقط «دیده‌شده‌ها» یا فقط «در انتظار تماشا» (با صفحه‌بندی)
- مشاهده‌ی جزئیات هر اثر
- ویرایش عنوان، نوع، سال، وضعیت، امتیاز و نقد (و پاک کردن موارد اختیاری)
- حذف اثر (با تأیید)

### اطلاعات هر اثر

| فیلد | توضیح |
|---|---|
| نام اثر | عنوان فیلم یا سریال (الزامی) |
| نوع | فیلم یا سریال (الزامی) |
| سال انتشار | میلادی، اختیاری |
| وضعیت | دیده‌شده / در انتظار تماشا (الزامی) |
| امتیاز | عدد ۱ تا ۱۰، اختیاری |
| نقد شخصی | نظر خودت، اختیاری (تا ۱۵۰۰ کاراکتر) |

## ۱) ساخت بات در بله و گرفتن توکن

1. در بله `@botfather` را جستجو کن و باز کنش.
2. `/start` را بفرست و گزینه‌ی ساخت ربات جدید را بزن.
3. یک اسم و یک نام کاربری برای بات بده (نام کاربری معمولاً باید به `bot` ختم شود).
4. در پایان BotFather یک **توکن** می‌دهد؛ شبیه `123456789:AbCdEf...`. آن را کپی کن.

> ⚠️ توکن مثل رمز عبور بات توست. به کسی نده و روی GitHub نگذار. اگر لو رفت، از BotFather توکن جدید بگیر.

## ۲) نصب و اجرا (Windows / PyCharm)

نیازمندی: Python 3.10 یا بالاتر.

1. پوشه‌ی پروژه را در PyCharm باز کن.
2. در Terminal خود PyCharm (پایین صفحه) یک محیط مجازی بساز و فعالش کن:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

اگر PowerShell اجازه‌ی فعال‌سازی نداد، یک‌بار این را بزن و دوباره فعال کن:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

3. کتابخانه‌ها را نصب کن:

```powershell
python -m pip install -r requirements.txt
```

4. فایل `.env.example` را کپی کن و اسم کپی را `.env` بگذار.
5. فایل `.env` را باز کن و به‌جای `PUT_YOUR_BALE_BOT_TOKEN_HERE` توکن خودت را بگذار:

```text
BALE_BOT_TOKEN=123456789:AbCdEf...
```

6. بات را اجرا کن:

```powershell
python bot.py
```

اگر همه‌چیز درست باشد این را می‌بینی: `Connected as @اسم_بات_تو`. برای توقف: `Ctrl+C`.

## ۳) طرز استفاده

1. در بله بات خودت را باز کن و `/start` را بفرست. منوی دکمه‌ها پایین صفحه ظاهر می‌شود.
2. **➕ افزودن اثر**: بات قدم‌به‌قدم می‌پرسد: اسم ← نوع ← سال (قابل رد کردن) ← وضعیت. اگر «دیدمش» را انتخاب کنی، امتیاز و نقد را هم می‌پرسد (هر دو قابل رد کردن). اگر «می‌خوام ببینمش» را بزنی، همان‌جا ذخیره می‌شود.
3. **📋 همه آثار / ✅ دیده‌شده‌ها / ⏳ در انتظار تماشا**: فهرست را می‌بینی. روی اسم هر اثر بزن تا جزئیاتش باز شود.
4. در صفحه‌ی جزئیات:
   - «✅ دیدمش» وضعیت را سریع عوض می‌کند
   - «✏️ ویرایش» ← انتخاب بخشی که می‌خواهی عوض شود (عنوان، نوع، سال، وضعیت، امتیاز، نقد)
   - «🗑 حذف» ← بعد از تأیید حذف می‌شود
5. هر وقت وسط کاری پشیمان شدی `/cancel` یا دکمه‌ی «❌ انصراف» را بزن.

دستورهای متنی معادل: `/add` `/list` `/watched` `/watchlist` `/cancel` `/help`

## ۴) اجرای تست‌ها

```powershell
python -m unittest discover -v
```

تست‌ها یک پایگاه‌داده‌ی موقت می‌سازند و به دیتای واقعی تو دست نمی‌زنند.

## ساختار پروژه

```text
CineLog/
├── bot.py            # حلقه‌ی اصلی: گرفتن پیام‌ها از بله و رسیدگی به خطاها
├── bale_api.py       # ارتباط با API بله
├── handlers.py       # منطق گفتگو: دکمه‌ها، مراحل افزودن/ویرایش، نمایش فهرست
├── database.py       # ساخت جدول‌ها و عملیات SQLite
├── config.py         # خواندن تنظیمات از فایل .env
├── tests/            # تست‌های خودکار
├── requirements.txt  # کتابخانه‌های لازم
├── .env.example      # نمونه‌ی تنظیمات (کپی کن و بشود .env)
└── .gitignore        # جلوگیری از آپلود .env و دیتابیس روی Git
```

## نکته‌ها

- بات با روش long polling کار می‌کند؛ نیازی به دامنه یا webhook نیست. **بات فقط تا وقتی کار می‌کند که `python bot.py` در حال اجراست** (کامپیوتر روشن و برنامه باز). برای اجرای دائمی باید روی یک سرور اجرایش کنی.
- داده‌ها در فایل `cinelog.db` کنار پروژه ذخیره می‌شوند. برای پشتیبان‌گیری همین فایل را کپی کن.
- اگر وسط یک مرحله (مثلاً بین پرسیدن اسم و نوع) بات ری‌استارت شود، آن مرحله فراموش می‌شود و دوباره از «➕ افزودن اثر» شروع می‌کنی؛ داده‌های ذخیره‌شده‌ی قبلی سالم می‌مانند.
- بات فقط در چت خصوصی کار می‌کند و پیام‌های گروه را نادیده می‌گیرد.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `Please put your Bale bot token...` | فایل `.env` را نساخته‌ای یا توکن داخلش نیست |
| `Bale rejected the bot token` | توکن اشتباه کپی شده؛ دوباره از BotFather بگیر |
| `Could not fetch updates (Network error...)` | اینترنت قطع است یا بله در دسترس نیست؛ بات خودش دوباره تلاش می‌کند |
| دکمه‌ها پایین صفحه نیست | یک‌بار `/start` بفرست |
| `ModuleNotFoundError` | محیط مجازی فعال نیست یا مرحله‌ی نصب کتابخانه‌ها را نزده‌ای |
